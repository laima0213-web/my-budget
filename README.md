# 📒 우리집 가계부 (my-budget)

가족이 쓰던 엑셀 **「1인 가계부 양식」** 7개 시트(사용법·월간요약·거래내역·설정·연간추이·자산추이·고정비)를
폰에서 앱처럼 쓰도록 옮긴 PWA입니다. 홈 화면에 추가하면 앱처럼 열립니다.

- 폰 화면 **390px 한 손 조작** 기준 (가로 스크롤 없음)
- 숫자는 전부 **tabular-nums** 로 정렬, 파스텔 크림·민트·세이지 톤, 아이콘은 전부 SVG(기기별 이모지 차이 없음)
- 엑셀과 **같은 계산 규칙** — 실질 지출 = 지출 + 할부 + 카드할인, 수지 = 수입 − 실질 지출, 이체는 합계 제외, 저축률 = 수지 ÷ 수입

## 화면

| 탭 | 내용 |
|---|---|
| 📊 요약 | 이번 달 수입 · 실질 지출 · 수지(전월 대비) · 저축률(목표 배지) · 순자산, **한달 달력·주별 지출 그림 카드(달력으로 바로가기)**, 분류별 표(전월 대비·예산 막대·사용률), 결제수단별 청구액(사용액·카드할인·청구액), 최근 6개월 차트 — **분류·결제수단 줄을 누르면 그 달 상세 내역이 바로 아래 펼쳐지고(다시 누르면 접힘), 펼친 줄을 누르면 그 거래를 고칠 수 있어요** |
| 🧾 거래 | 위쪽 **[📅 한달 달력 \| 📋 내역 목록]** 전환(기본은 달력). **달력** — 주별 지출 총액 막대 그림(최고 주 강조·주 평균 점선), 월~일 7열 달력에 날짜와 **그날 지출 금액을 정확한 숫자로**(1,184,001 — 수입·항목 줄임표 없이) 히트맵 색과 함께 표시, 매 주 아래 주간 총액 띠, 날짜를 누르면 그날 내역·주차를 누르면 그 주 내역이 펼쳐지고 `＋ 이날 거래 추가`로 날짜가 채워진 입력 시트가 열림. **내역 목록** — 월 이동, 검색, 구분·분류·결제수단 필터, 날짜별 묶음 + 일 합계, 줄을 누르면 수정·삭제, 구분↔분류 불일치·없는 결제수단 점검 안내 |
| ＋ | 빠른 입력 — 날짜·구분 칩(지출/수입/이체/카드할인/할부)·분류 칩(최근 쓴 것부터)·금액 키패드(+1만/+5천/+1천)·항목·결제수단·메모 |
| 📈 추이 | 연간추이(월별 표·그래프·분류별 연간 합계) / 자산추이(월별 자산 입력, 총자산·순자산·전월 대비·그 달 수지, 순자산 그래프, 항목명 편집) |
| 🔁 고정비 | 매달 반복 항목 추가·수정·삭제, **이번 달 거래내역에 넣기 / 이번 달에서 빼기**(한 번에·줄별로), 이미 넣은 달은 중복 확인 후 건너뜀, 0원 항목은 넣기·빼기에서 제외 |
| ⚙️ 설정 | 분류(지출 25개+)·수입 분류·결제수단 추가/수정/순서/삭제, 분류별 월 예산, 목표 저축률, PIN 잠금, **엑셀(.xlsx) 내보내기**, JSON 백업/가져오기 |

## 파일

```
my-budget/
  index.html        화면 틀 (공개 — 개인정보 없음)
  styles.css        디자인
  core.js           계산 엔진 (엑셀 수식과 같은 규칙, 화면과 분리)
  app.js            화면·저장·동기화·내보내기  (맨 위 CLOUD 한 곳만 설정)
  manifest.json     PWA 설정
  sw.js             오프라인 캐시
  icon-180/192/512.png
  seed-ledger.json  ← 개인 실데이터 + PIN 해시 · .gitignore 로 제외 (공개 저장소에 올리지 않음)
```

## 데이터가 있는 곳

1. **이 기기** — localStorage(`myBudget.v1`). 앱을 지우면 함께 사라지므로 JSON 백업을 권장.
2. **seed-ledger.json** — 엑셀에서 옮긴 초기 자료(59건) + PIN 해시. 공개 저장소에는 올리지 않습니다.
3. **Firebase 실시간 DB** — `app.js` 맨 위 `CLOUD` 에 연결 정보가 들어 있습니다.

## Firebase 연결 (설정 완료)

```js
firebaseConfig: { ...family-dashboard-782e7 프로젝트... },   // apiKey 등은 공개되어도 되는 값
DB_ROOT: "ledgers/41CtUwOvUPZyYcflaxJq0PiCFUx2",           // 이 경로의 ref 에서만 읽고 씀
ACCOUNT: "mybudget@family.local"                            // 로그인 폼에 기본 표기
```

- **처음 접속하면 로그인 화면이 자동으로 뜹니다** (0원 빈 가계부가 아니라). 이메일은 `mybudget@family.local` 로 미리 채워져 있고,
  비밀번호만 넣으면 클라우드의 59건이 바로 보입니다. 그 뒤로는 새로고침해도 로그인이 유지되고, 앱을 열 때 PIN(4자리)을 물어봅니다.
- **비밀번호는 코드에 없습니다.** 처음 한 번만 화면에서 직접 입력하면 그 기기에 기억됩니다.
- 루트에는 `.write: false` 라서 반드시 `db.ref(DB_ROOT).update({...})` 로 저장합니다.
- PIN 잠금은 `sha256("my-budget|v1|" + salt + "|" + PIN)` 해시만 `auth/pinHash`·`auth/salt` 로 저장합니다.
- 처음 로그인할 때: 이 기기에 기록이 있으면 그 기록을, 빈 기기면 DB 내용을 따릅니다(빈 기기가 DB를 지우지 않음).
- 같은 주소(github.io)에 있는 가족 대시보드와 **로그인이 섞이지 않도록**, 가계부는 이름이 다른 `budget` 앱으로 Firebase에 붙습니다.

## 오프라인 / 업데이트

`sw.js` 가 앱 틀만 캐시합니다. 평소에는 네트워크에서 먼저 받아 수정이 바로 반영되고,
인터넷이 없을 때만 캐시로 열립니다. (거래내역·자산 같은 개인 데이터는 캐시하지 않습니다)

## 엑셀 내보내기

SheetJS(CDN)로 **6장짜리 `.xlsx`** 를 만듭니다 — 거래내역·월간요약·설정·연간추이·자산추이·고정비.
엑셀에서 그대로 열려 원본 양식에 붙여 넣을 수 있습니다. (인터넷이 없으면 안내 문구가 뜹니다)

## 검증

`core.js` 는 화면 없이도 돌아가도록 만들었습니다.
제작할 때 쓴 검산 스크립트(작업 공간 `work/budget/verify_core.py`, dukpy)로 엑셀 원본과 같은 값이 나오는지 확인했습니다 — 2026-11 실질 지출 합계와 결제수단별 금액이 1원 오차 없이 일치합니다.
